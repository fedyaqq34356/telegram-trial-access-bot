# Инструкция по работе с ботом

---

## Для девушек

### Как проверить свой коэффициент

1. Открыть бота в Telegram.
2. Нажать **«Старт»** или написать `/start`.
3. Бот попросит отправить ID из приложения Halo Live.
4. Открыть Halo Live, скопировать числовой ID (например: `538657294`).
5. Отправить этот ID боту.
6. Подождать несколько секунд — бот покажет результат.

Если бот написал «Требуется дополнительная проверка» — нужно подождать, пока администратор введёт 2FA-код. Результат придёт автоматически.

**Важно:** между проверками нужно ждать 15 секунд.

---

### Что означает ответ бота

```
Ваш ID: 538657294
Агентство: TosAgency

Коэффициент в профиле: 0.12
Коэффициент за последние 30 дней: 0.09

Месячный заработок: 15,000 coins
Уровень: B

✅ Всё в норме
```

| Поле | Описание |
|---|---|
| **Коэффициент в профиле** | Общий коэффициент. Должен быть ниже **0.18** для всех |
| **Коэффициент за 30 дней** | За последний месяц. Лимит зависит от уровня |
| **Месячный заработок** | Coins за текущий месяц |
| **Уровень** | S / A / B / C / D по заработку |

---

### Таблица уровней

| Уровень | Заработок | Лимит 30 дней | Наказание |
|---|---|---|---|
| **S** | от 45 000 | нет ограничения | нет |
| **A** | 20 000 – 44 999 | до 0.25 | Бан 1 день |
| **B** | 7 000 – 19 999 | до 0.18 | Бан 3 дня |
| **C** | 2 000 – 6 999 | до 0.18 | Бан 7 дней |
| **D** | меньше 2 000 | до 0.12 | Перманентный бан |

> Коэффициент **в профиле** должен быть ниже 0.18 у всех, независимо от уровня.

## Для администраторов

### Кнопки в меню

| Кнопка | Что делает |
|---|---|
| **Проверить ID** | Вручную проверить ID девушки (результат приходит вам) |
| **История проверок** | Последние 20 проверок: кто, когда, что нашли |
| **Пользователи** | Список всех участников на пробном периоде (файл .txt) |
| **На пробном периоде** | Участники со временем окончания периода |
| **Проверка** | Проверить присутствие всех в рабочем чате и учебной группе |
| **Удалить участника** | Ввести Telegram ID → удалить из базы и чатов |
| **Skip пробный период** | Ввести Telegram ID → перевести в статус «Оставлен» |
| **Добавить администратора** | Ввести Telegram ID → дать права админа |
| **Убрать администратора** | Ввести Telegram ID → снять права |
| **Список администраторов** | Показать всех администраторов |
| **Агентства** | Список подключённых агентств |
| **Добавить агентство** | Пошагово добавить новое агентство |
| **Редактировать агентство** | Изменить данные существующего агентства |
| **Удалить агентство** | Удалить агентство по номеру |

---

### Как вручную проверить ID

1. Нажать **«Проверить ID»**.
2. Отправить числовой ID (7–15 цифр).
3. Бот найдёт агентство и покажет результат вам.

Результат точно такой же, как видит девушка. Полезно для проверки до/без ведома девушки.

---

### Как добавить агентство

1. Нажать **«Добавить агентство»**.
2. Бот попросит ввести данные по шагам:
   - Название агентства (например: `TosAgency`)
   - Логин 1-го шага (`account`)
   - Пароль 1-го шага (`password`)
   - Логин 2-го шага — название агентства в панели (`aemail`)
   - Пароль 2-го шага (`apassword`)
3. Бот спросит, нужна ли 2FA — нажать **«Да»** или **«Нет»**.
4. Агентство сохранено. Бот начнёт искать девушек в нём с первой же проверки.

Для отмены в любой момент написать `/cancel`.

---

### Как редактировать агентство

1. Нажать **«Редактировать агентство»**.
2. Бот покажет список с номерами — ввести номер нужного агентства.
3. Бот покажет кнопки с полями: Название, Логин, Пароль 1, Email, Пароль 2, 2FA.
4. Нажать нужное поле.
5. Ввести новое значение (для 2FA — выбрать Да/Нет).
6. Готово.

---

### Как удалить агентство

1. Нажать **«Удалить агентство»**.
2. Бот покажет список с номерами.
3. Ввести номер агентства для удаления.
4. Агентство удалено из базы. Новые проверки по нему не будут выполняться.

---

### Что делать, когда бот просит код 2FA

Это происходит при первом входе в агентство с двухфакторной аутентификацией. После этого сессия сохраняется и 2FA больше не нужна.

1. Бот присылает: «🔐 Требуется код 2FA для агентства ...»
2. Открыть **Google Authenticator** на телефоне.
3. Найти код для нужного агентства (6 цифр, обновляется каждые 30 секунд).
4. Отправить эти 6 цифр боту.
5. Бот авторизуется и отправит результат девушке автоматически.

Если бот написал «Неверный код» — откройте Authenticator снова (код мог обновиться) и отправьте новый.

> Сессия сохраняется до перезапуска бота или истечения на сервере. После перезапуска при первой проверке снова попросит 2FA.

---

### История проверок

Нажать **«История проверок»** — бот покажет последние 20 проверок:

- username и Telegram ID пользователя
- ID девушки из Halo Live
- Дата и время
- Агентство (или «не найден»)
- Уровень, коэффициенты, статус риска

## Запуск и обслуживание

### Запустить бота

```bash
cd /путь/к/боту
python main.py
```

### Запустить в фоне (systemd)

Создать файл `/etc/systemd/system/halo-bot.service`:

```ini
[Unit]
Description=Halo Live Telegram Bot
After=network.target

[Service]
WorkingDirectory=/путь/к/боту
ExecStart=/путь/к/боту/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable halo-bot
sudo systemctl start halo-bot
```

Проверить статус:

```bash
sudo systemctl status halo-bot
sudo journalctl -u halo-bot -n 50
```

### Перезапустить бота

```bash
sudo systemctl restart halo-bot
```

---

### Если бот не отвечает

1. Проверить статус: `sudo systemctl status halo-bot`
2. Посмотреть логи: `sudo journalctl -u halo-bot -n 50`
3. Если ошибка «сеть недоступна» — проблема на стороне Halo Live, подождите и попробуйте снова.
4. Если ошибка в коде — пришлите вывод лога разработчику.
