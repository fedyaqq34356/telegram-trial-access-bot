# Telegram-бот управления участниками и проверки коэффициентов Halo Live

## Описание

Бот выполняет две независимые функции:

1. **Управление пробным периодом** — отслеживает участников двух Telegram-чатов (рабочий чат и учебная группа), уведомляет администраторов об истечении пробного периода, позволяет кикать или оставлять пользователей.

2. **Проверка коэффициентов Halo Live** — девушки-стримеры отправляют свой ID из приложения Halo Live, бот подключается к агентскому панелю и возвращает статистику: коэффициент неприязни в профиле, коэффициент за 30 дней, уровень (S/A/B/C/D) и статус риска.

## Функция 1: Пробный период

### Как работает:

- При подаче заявки на вступление в рабочий чат бот автоматически одобряет её и запускает пробный период.
- Планировщик каждый час проверяет истекшие пробные периоды и уведомляет администраторов.
- За 24 часа до истечения администраторы получают предупреждение.
- Администратор нажимает «Оставить» или «Кикнуть».
- Если пользователь покидает учебную группу — он автоматически удаляется из рабочего чата.

### Кнопки администратора:

| Кнопка | Действие |
|---|---|
| Пользователи | Список всех пользователей (файлом) |
| На пробном периоде | Активные пробные периоды с оставшимся временем |
| Проверка | Проверить присутствие в чатах |
| Удалить участника | Ввести ID и удалить из чатов и базы |
| Skip пробный период | Перевести пользователя в статус «Оставлен» |
| Добавить администратора | Добавить по Telegram ID |
| Убрать администратора | Удалить по Telegram ID |
| Список администраторов | Показать всех администраторов |
| История проверок | Последние 20 проверок коэффициентов |
| Агентства | Список подключённых агентств Halo Live |

## Функция 2: Проверка коэффициентов

### Как работает для девушки:

1. Девушка открывает бот и нажимает `/start`.
2. Бот просит отправить ID из приложения Halo Live.
3. Девушка отправляет числовой ID (пример: `538657294`).
4. Бот ищет ID во всех подключённых агентствах.
5. Бот отвечает статистикой и статусом риска.

### Логика уровней (по MonthlyIncome):

| Уровень | Месячный доход |
|---|---|
| S | ≥ 45 000 монет |
| A | 20 000 – 44 999 монет |
| B | 7 000 – 19 999 монет |
| C | 2 000 – 6 999 монет |
| D | < 2 000 монет |

> Уровень рассчитывается по полю `MonthlyIncome` из API, а не по полю `AnchorGrade`.

### Лимиты риска:

- **DownRate (профиль)**: должен быть ниже 0.18 для **всех** уровней.
- **RealDownRate (30 дней)**:

| Уровень | Лимит 30 дней |
|---|---|
| S | нет ограничения |
| A | < 0.25 |
| B | < 0.18 |
| C | < 0.18 |
| D | < 0.12 |

### Возможные наказания при превышении лимита 30 дней:

| Уровень | Наказание |
|---|---|
| S | нет |
| A | ⛔ Бан на 1 день |
| B | ⛔ Бан на 3 дня |
| C | ⛔ Бан на 7 дней |
| D | ⛔ Перманентный бан |

Откройте `agencies.py` и добавьте словарь в список `AGENCIES`:

```python
{
    "name": "НазваниеАгентства",
    "url": "https://admin.livegirl.me",
    "account": "логин_первого_шага",
    "password": "пароль_первого_шага",
    "aemail": "логин_второго_шага",
    "apassword": "пароль_второго_шага",
    "tfa_required": True   # или False
}
```

Перезапустите бот после изменения.

## 2FA (двухфакторная аутентификация)

Если агентство защищено Google Authenticator:

1. Девушка отправляет ID — бот начинает поиск.
2. Девушка получает: «⏳ Требуется дополнительная проверка. Ожидайте ответа...»
3. Все администраторы получают запрос с названием агентства.
4. Один администратор вводит 6-значный код из Google Authenticator.
5. Бот завершает поиск и отправляет результат девушке.

Если код введён неверно — бот сообщает об ошибке, сессия сохраняется, можно ввести заново.

## История проверок

Кнопка «История проверок» показывает последние 20 проверок:

- Telegram username и Halo Live ID
- Дата и время
- Агентство и уровень (если найден)
- Коэффициенты и статус риска

Каждая проверка (найден / не найден) сохраняется в таблицу `check_history` в `bot.db`.

## Деплой через systemd

Создайте `/etc/systemd/system/halo-bot.service`:

```ini
[Unit]
Description=Halo Live Telegram Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/путь/к/боту
ExecStart=/usr/bin/python3 /путь/к/боту/main.py
Restart=always
RestartSec=5
EnvironmentFile=/путь/к/боту/.env

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable halo-bot
sudo systemctl start halo-bot
sudo systemctl status halo-bot
# Логи:
sudo journalctl -u halo-bot -f
```

## Устранение неполадок

**Бот не запускается**
— Проверьте `.env`: все переменные должны быть заполнены и корректны.

**Не реагирует на вступление в чат**
— Бот должен быть администратором с правами «Пригласить участников» и «Блокировать участников».
— В настройках чата включите «Заявки на вступление».

**Ошибка 2FA**
— Вводите текущий (не истёкший) код — он действует 30 секунд.
— Убедитесь, что часы на телефоне синхронизированы.

**ID не найден**
— Проверьте, что ID взят из приложения Halo Live.
— Убедитесь, что девушка зарегистрирована в одном из подключённых агентств.

**Бот завис / не отвечает**
```bash
sudo systemctl restart halo-bot
sudo journalctl -u halo-bot -n 50
```
