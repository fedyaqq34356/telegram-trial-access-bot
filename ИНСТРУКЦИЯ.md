ДЛЯ ДЕВУШЕК

Откройте бота и нажмите Старт. Бот попросит отправить ваш числовой ID из приложения Halo Live. Скопируйте его и отправьте.

Бот покажет:
- коэффициент в профиле (должен быть ниже 0.18)
- коэффициент за последние 30 дней
- месячный заработок и уровень
- есть ли риск и возможное наказание

Если бот написал "Требуется дополнительная проверка" - ждите, администратор введёт код и результат придёт автоматически. Между проверками нужно подождать 15 секунд.

Уровни по заработку:
S - от 45 000 монет, ограничений нет
A - от 20 000, коэффициент 30 дней не выше 0.25, иначе бан на 1 день
B - от 7 000, коэффициент 30 дней не выше 0.18, иначе бан на 3 дня
C - от 2 000, коэффициент 30 дней не выше 0.18, иначе бан на 7 дней
D - меньше 2 000, коэффициент 30 дней не выше 0.12, иначе постоянный бан

ДЛЯ АДМИНИСТРАТОРОВ

Кнопки в меню:

Проверить ID - вручную проверить ID девушки, результат придёт вам
История проверок - последние 20 проверок с деталями
Пользователи - список всех на пробном периоде
На пробном периоде - участники с датой окончания
Проверка - проверить присутствие всех в рабочем чате и учебной группе
Удалить участника - ввести Telegram ID и удалить из базы и чатов
Skip пробный период - ввести Telegram ID и перевести в статус Оставлен
Добавить администратора - ввести Telegram ID
Убрать администратора - ввести Telegram ID
Список администраторов - показать всех
Агентства - список подключённых агентств
Добавить агентство - пошагово добавить новое
Редактировать агентство - изменить данные существующего
Удалить агентство - удалить по номеру

Для отмены любого действия - кнопка "Отмена" под сообщением.

---

Добавление агентства:
1. Нажать "Добавить агентство"
2. Ввести название
3. Ввести логин первого шага
4. Ввести пароль первого шага
5. Ввести логин второго шага (название агентства в панели)
6. Ввести пароль второго шага
7. Выбрать, нужна ли двухфакторная аутентификация

---

Если бот просит код из Google Authenticator:
Это происходит при первом входе. После этого сессия сохраняется и код больше не нужен до перезапуска бота.
1. Открыть Google Authenticator
2. Найти 6-значный код нужного агентства
3. Отправить его боту
4. Бот войдёт и пришлёт результат девушке автоматически

Если бот написал "Неверный код" - код мог обновиться, откройте Authenticator снова и пришлите новый.

ЧТО ДОБАВЛЕНО В БОТ

Добавлена проверка коэффициента через панели агентств. Девушка отправляет свой числовой ID из приложения Halo Live, бот заходит во все подключённые агентства, находит её и показывает коэффициент в профиле, коэффициент за 30 дней, месячный заработок, уровень и есть ли риск наказания.

Уровни присваиваются автоматически по заработку: S, A, B, C, D. Для каждого уровня свой лимит коэффициента за 30 дней. Если превышен - бот предупреждает и показывает возможное наказание.

Сессии агентств сохраняются. Бот входит в агентство один раз, потом использует сохранённую сессию. Если сессия истекла - заходит заново автоматически.

Если у агентства включена двухфакторная аутентификация, бот просит администратора ввести 6-значный код из Google Authenticator. Девушка ждёт и получает результат автоматически после того, как администратор введёт код. Администратор может отменить проверку кнопкой.

Добавлена защита от спама: между проверками для обычных пользователей нужно ждать 15 секунд.

Добавлен раздел управления агентствами: добавить, редактировать любое поле, удалить, просмотреть список.

Добавлена история проверок: последние 20 проверок с указанием кто проверял, какой ID, когда, какое агентство, уровень и был ли риск.

Администратор может вручную проверить любой ID через кнопку "Проверить ID" - результат придёт ему, а не девушке.

Добавлена кнопка "Отмена" к каждому действию, которое ожидает ввода от администратора.
